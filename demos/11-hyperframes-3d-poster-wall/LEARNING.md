## 代码事实

- Composition：1920×1080、30fps、293 帧（9.7667s）。
- CSS perspective 固定为 2200px。
- `camera` 和 `tilt-world` 是两个不同 transform 层。
- 卡片最终位置写在静态 CSS；timeline 只描述它们从哪里来。
- 页面只有一条 `gsap.timeline({ paused: true })`，注册到 `window.__timelines.main`。
- 所有默认图片都是本项目原创 SVG；`data-var-src` 允许本地授权照片覆盖。

## 实现推断

- 教程没有要求逐像素复制，因此保留“标题—分组组装—整体侧倾—镜头巡航”的机制，视觉语言改为原创的 “Midnight Field Notes”。
- 大量卡片若同时使用同一路径，会失去空间组织感，因此用上、左、右、下四个方向组建立因果。
- 网格放在负 Z，前景卡片分布在多个 Z 深度，使侧倾后能够出现稳定但不过度的视差。

## 本地决定

- 默认 fixture 使用 16 张原创抽象 SVG，保证 clean checkout 可预览和渲染。
- 私人照片只通过被忽略的 `assets/local/` 与变量文件覆盖，不进入公开仓库。
- 标题采用暖金，正文为纸张米白，技术读数使用青绿色；背景使用深炭黑与低对比网格。
- 唱片是纯 CSS 图形，不引入额外图片授权。

## 验收关键帧

`0.15 / 0.55 / 0.95 / 1.55 / 2.15 / 3.25 / 4.25 / 5.25 / 7.25 / 9.25s`

重点核对：

1. 标题确实从中线展开，而不是只改变透明度；
2. 四个方向组的路径可辨认，相邻卡片有 0.08–0.12s 的错峰；
3. 主要组装完成后才开始整体倾斜；
4. camera 巡航与 tilt 分层，右侧区域逐步获得主视觉权重；
5. 尾帧保留完整空间，不淡出。

## 残余问题

- 本地照片的主体位置各不相同，覆盖 fixture 时仍需逐张调整 `object-position`。
- CSS 3D 在不同浏览器的抗锯齿表现可能略有差异，最终交付以 HyperFrames 的 Chromium 渲染结果为准。

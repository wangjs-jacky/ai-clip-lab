# Trig Projection Room

> 用一个共享相位，把单位圆、后墙正弦波与地面余弦波连接成可验证的伪 3D 空间。

## 这是什么

这是一个 11 秒、1920×1080、30fps 的 HyperFrames Demo。它使用 Canvas 2D 和透视投影公式模拟三面空间，不依赖 Three.js。画面中的三个亮点、两条曲线和所有数值都来自同一个 `theta`，因此不会出现“看起来同步、数学上却无关”的假动画。

## 前置条件

- Node.js 20 或更高版本
- 可用的 Chromium/Chrome
- FFmpeg（只在检查最终 MP4 时需要）

## 运行步骤

1. 进入本目录。
2. 运行测试与 HyperFrames 检查：

   ```bash
   npm run check
   ```

3. 打开预览：

   ```bash
   npm run dev
   ```

4. 渲染视频：

   ```bash
   npm run render -- --quality high --output renders/trig-room.mp4
   ```

## 验证检查点

- `0–1.2s`：三面投影舱被构建出来。
- `1.2–2.4s`：单位圆与两条投影关系出现。
- `3–9s`：同一相位完成一整圈，正弦与余弦同步描绘。
- `9–11s`：回到 `2π`，所有状态与起点闭合。
- `node --test projection.test.mjs` 会验证五个基准相位、首尾闭合、共享分量和确定性。

## 常见问题

### 为什么不用 Three.js？

教程的核心是“二维元素经过坐标换算后形成空间感”。Canvas 2D 足以完整表达这个机制，并且更容易验证每个点的数学来源。

### 为什么不能给三个图形分别写动画？

那会丢失教程最有价值的因果关系。本 Demo 只 tween 一个相位状态，单位圆、正弦、余弦都在同一帧重新计算。

## 总结

这个案例展示的不是一个 3D 特效模板，而是一种实现顺序：先锁定共享数据关系，再做投影，最后才给这个唯一状态加时间。
